## ⌨️ Phím Tắt Điều Khiển
- **Phím H**: Ẩn / Hiện Bảng Menu Điều Khiển.
- **Lăn Chuột (Mouse Wheel)**: Thu phóng Camera mượt mà từ 0.25x đến 3.5x.
- **Giữ Chuột Phải**: Kích hoạt nhấp nhả Auto-Boost thông minh.
